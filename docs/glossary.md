# 用語集

決済(Stripe Connect)の用語と、本サイトに固有の用語の一覧です。Stripe の用語は、Stripe の日本語の公式ドキュメントの表記に合わせています。

## 決済(Stripe)

| 用語 | 意味 |
|---|---|
| オーソリ | カードの利用枠を確保すること。この時点では売上は確定しない。有効期限があり、期限までにキャプチャーしなければ取り消される。要件定義書と基本設計書では「仮押さえ」と書く |
| キャプチャー | オーソリした金額を、売上として確定すること。生産者の画面では「代金を確定する」と表示する。要件定義書と基本設計書では「代金の確定」と書く |
| 3D セキュア | カード決済で、カード保有者の本人確認を行う認証 |
| Checkout Session | 1回の購入手続きを表す Stripe のオブジェクト。本サイトでは、Elements を本サイトのページに組み込む形(`ui_mode: elements`)で使う |
| Elements | Stripe が提供する入力フォームの UI 部品。本サイトでは、Payment Element(カード情報の入力)と Contact Details Element(メールアドレスの入力)を使う。カード情報は本サイトのサーバーを経由しない |
| 連結アカウント | Stripe Connect で、プラットフォームに接続した販売者の Stripe アカウント。本サイトでは、生産者ごとに1つ作成する |
| プラットフォームアカウント | 連結アカウントを管理する側の Stripe アカウント。本サイトでは、管理者のアカウント。要件定義書と基本設計書では「プラットフォームのアカウント」と書く |
| ダイレクト支払い | 連結アカウント上に直接作成する支払い。代金はプラットフォームアカウントを経由しない |
| アプリケーション手数料 | 支払いごとに、プラットフォームアカウントが受け取る手数料(`application_fee_amount`)。Stripe の日本語のドキュメントでは「プラットフォーム手数料」とも表記される |
| 入金 | Stripe の残高から、銀行口座に振り込まれること(payout) |
| 送金 | Stripe アカウントの間で資金を移動すること(transfer)。本サイトでは使わない |
| 埋め込みコンポーネント | Stripe Connect が提供する UI 部品。本サイトのページに埋め込み、生産者がアカウントの登録と管理、残高の確認、不審請求への対応などに使う。基本設計書では「埋め込みの部品」と書く |
| 不審請求の申し立て | カード保有者が、カード発行会社に支払いの取り消しを求めること。カード業界では「チャージバック」と呼ぶ。文書では「不審請求」と略す |
| 照会 | 不審請求の申し立ての前に、カード発行会社が取引の情報を求める手続き |
| 反証資料 | 不審請求の申し立てに反論するために提出する資料。要件定義書と基本設計書では「証拠」と書く |
| サンドボックス | Stripe のテスト用の環境。本番環境の資金とデータに影響しない |

| 用語 | 意味 |
|---|---|
| 方式検証 | 設計の前提になる外部サービスの動作を、小さなコードで確認する作業。コードは `spikes/` に置く |
