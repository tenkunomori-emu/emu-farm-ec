## 4. 画面設計

### 4.1 画面一覧

画面IDの付け方: 来訪者向けは `P-`、管理画面は `A-` とする。番号の十の位は、フェーズに合わせる(1〜19: フェーズ1、20〜: フェーズ2)。
「見られる役割」は、[要件定義書 第5.1節](01-requirements.md#51-役割と権限)の役割を使う。

### 4.2 画面遷移

#### 4.2.1 来訪者(フェーズ1)

```mermaid
flowchart LR
  QR["イベント会場のQR<br/>検索・SNS"] --> P01
  P01["P-01 トップ"] --> P02["P-02 紹介"]
  P01 --> P03["P-03 イベント一覧"] --> P04["P-04 イベント詳細"]
  P01 --> P05["P-05 商品一覧"] --> P06["P-06 商品詳細"]
  P01 --> P07["P-07 お知らせ一覧"] --> P08["P-08 お知らせ詳細"]
  P01 --> P09["P-09 協賛のご案内"]
  P06 -- "購入する" --> EXT["他の販売サイト"]
  P04 --> P10["P-10 お問い合わせ"]
  P09 --> P10
  P10 --> P11["P-11 完了"]
  P01 --> P12["P-12 メール/LINE登録"]
```

- お問い合わせ(P-10)とメール/LINE登録(P-12)へは、どの画面からも、共通のフッターで移動できる。
- イベント会場のQRは、P-01ではなく、P-04(そのイベントの詳細)やP-12(登録)へ直接つなぐこともできる。どこへつなぐかは、イベントごとに決める。

#### 4.2.2 管理画面(フェーズ1)

```mermaid
flowchart LR
  A01["A-01 ログイン"] --> A02["A-02 管理トップ"]
  A02 --> A03["A-03 お知らせの管理"]
  A02 --> A04["A-04 イベントの管理"]
  A02 --> A05["A-05 問い合わせの確認"]
  A02 -- "管理者のみ" --> A06["A-06 メンバーの管理"]
```

#### 4.2.3 購入の流れ(フェーズ2、参考)

```mermaid
flowchart LR
  P06["P-06 商品詳細<br/>送料を表示"] --> P20["P-20 カート<br/>送料を表示"]
  P20 --> P21["P-21 購入手続き<br/>会員登録なし"]
  P21 --> P22["P-22 注文完了"]
  P22 -. "注文確認メール" .-> P23["P-23 注文内容の確認"]
```
