# 決定事項の記録

会議やメールで合意したことを、1件1行で記録する。議事録そのものは、主催者とメンバーが管理し、このリポジトリには置かない。
ここには、**何を決めたか**、**どの文書に反映したか**、**どの議事録に記録があるか**だけを書く。

- 個人名、連絡先、費用・契約の内容は書かない。
- 文書は、省略せずに「文書名 版(ファイル名)」の形で書く(例: 要件定義書 v1.1([01-requirements.md](01-requirements.md)))。
- メールで合意した場合も、その日の議事録に記録し、議事録の名前を書く。
- 大きな技術判断は、あわせて [ADR](adr/) に理由を残す。
- 決定を取り消した、または変えた場合は、行を消さずに、新しい行を追加する(「#3 を変更」のように書く)。
