# 要件から設計、テストへの対応表

要件定義書([01-requirements.md](01-requirements.md))で、フェーズが MVP の要件(機能要件と非機能要件)を、要件定義書と同じ順に並べ、設計のどこに対応しているかを示す。削除にした要件は入れない。

- 基本設計の列には、その要件に対応する基本設計書(02-basic-design.md)の ID か、ADR([adr/](adr/))の ID を書く。
- 列の足し方と、列を埋める工程は、開発の進め方([CONTRIBUTING.md](../CONTRIBUTING.md#工程とゲート))の「工程とゲート」のとおりにする。検証方法と受入条件は、要件定義書の要件の表にだけ書き、この表には写さない。
