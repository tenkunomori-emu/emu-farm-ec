# 方式検証のコード(Stripe)

Stripe のサンドボックスで、お金の流れの前提(生産者のアカウントの設定、返金、不審請求など)を確かめるコードです。本番のコードには使いません。確かめた結果は ADR に記録します(開発の進め方([CONTRIBUTING.md](../../CONTRIBUTING.md#工程とゲート))の「工程とゲート」)。

## 動かし方

1. Node.js 22.18 以上を使う(TypeScript のファイルを、ビルドせずにそのまま動かすため)。
2. このフォルダーで `npm install` を実行する。
3. `.env.example` を `.env` にコピーし、Stripe のサンドボックスの鍵を入れる。
4. `node --env-file=.env <ファイル名>` で動かす。

## 決まり

- Stripe のサンドボックスの鍵だけを使う。本番の鍵は入れない。
- `.env` はコミットしない(リポジトリの `.gitignore` で除いている)。
- 1つのファイルで1つのことを確かめ、何を確かめるかをファイルの冒頭に書く。
